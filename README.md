# structured-llm-frontend

Frontend for the [structured-llm](https://github.com/your-org/structured-llm) project.

## Stack

- [TanStack Start](https://tanstack.com/start)
- React 19
- TypeScript
- Tailwind CSS v4

## Development

Requires Node.js (recommended: use [nvm](https://github.com/nvm-sh/nvm)) or [Bun](https://bun.sh).

```sh
git clone <this-repository-url>
cd structured-llm-frontend
npm install   # or bun install
npm run dev   # or bun run dev
```

## Build

```sh
npm run build
```

## Preview

```sh
npm run preview
```
